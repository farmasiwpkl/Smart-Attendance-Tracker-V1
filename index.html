Connect your Google Sheet

Scans are sent to your own Google Sheet through a small Google Apps Script "Web App" — free, no server needed, stays entirely in your Google account.

This device auto-saves your staff list, session details and scan log as you go, so a refresh, crash, or accidental tab close won't lose progress.

How to set this up (one-time, ~3 minutes)

Already deployed the script before? Replace the code in your existing Apps Script project with the version below, save, then Deploy → Manage deployments → edit (pencil) → New version → Deploy. Your Web App URL stays the same.

  1. Open sheets.google.com and create a new blank spreadsheet — this becomes your attendance log.
  2. In the Sheet, go to Extensions → Apps Script.
  3. Delete anything in the editor and paste in the code below.
  4. Click the disk icon to save, name the project anything.
  5. Click Deploy → New deployment. Click the gear icon, choose type Web app.
  6. Set "Execute as" to Me, and "Who has access" to Anyone. Click Deploy, then authorize with your Google account when prompted.
  7. Copy the Web app URL it gives you and paste it into the field above.
function doPost(e) {
  var data = JSON.parse(e.postData.contents);

  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('Attendance');
  if (!sheet) {
    sheet = ss.insertSheet('Attendance');
    sheet.appendRow(['Session', 'Name', 'Jawatan', 'Date', 'Time']);
  }
  sheet.appendRow([data.session, data.name, data.jawatan, data.date, data.time]);
  return ContentService.createTextOutput(JSON.stringify({status: 'ok'}))
    .setMimeType(ContentService.MimeType.JSON);
}

Note: because Apps Script doesn't send back normal CORS headers, this app fires requests "blind" (it can't read a confirmation back). Use "Send test row" above to confirm it's wired up correctly.
